# 学生学分管理系统 (Student Credit Management System)

一个用 **C++17** 编写的简易学生学分管理系统，控制台交互，**零第三方依赖**，
数据以纯文本保存，编译即可运行。适合作为 C++ 课程设计 / 大作业的基础版本。

## 功能一览

| 序号 | 功能 | 说明 |
| --- | --- | --- |
| 1 | 添加学生 | 学号 + 姓名 + 专业，自动查重 |
| 2 | 显示全部学生 | 附带每人的已获学分与已修门数 |
| 3 | 删除学生 | 同时级联删除该生的所有成绩 |
| 4 | 添加课程 | 课程号 + 课程名 + 学分 |
| 5 | 显示全部课程 | —— |
| 6 | 删除课程 | 同时级联删除该课的所有成绩 |
| 7 | 录入 / 修改成绩 | 同一学生同一课程重复录入会自动覆盖（可用于补考、重修） |
| 8 | 查询学生成绩单 | 逐门列出学分、成绩、绩点，并汇总学分与 GPA |
| 9 | 学分排行榜 | 按已获学分降序，同分按学号升序 |
| 10 | 载入演示数据 | 一键生成 3 名学生、5 门课程和完整成绩 |
| 11 | 保存数据 | 也可在退出时自动保存 |

## 环境要求

- 支持 C++17 的编译器：`g++` 8.0+ / `clang++` 7.0+ / MSVC 2017+
- 无需任何第三方库，标准库即可

## 编译与运行

### 方式一：直接用 g++

```bash
# Windows (MinGW) / Linux / macOS 通用
g++ -std=c++17 -O2 -o scms src/main.cpp

# Windows 上会生成 scms.exe
./scms          # 数据文件默认为当前目录下的 data.txt
./scms my.txt   # 也可以自己指定数据文件名
```

### 方式二：用 Makefile

```bash
make        # 编译
make run    # 编译并运行
make clean  # 清理产物
```

### 方式三：Visual Studio / Dev-C++

新建控制台项目，把 `src/main.cpp` 加进去即可，无需其他配置。

> **中文乱码提示**：程序已自动把 Windows 控制台的输入输出代码页切到 UTF-8（`CP_UTF8`）。
> 如果仍显示乱码，请把源码文件保存为 **UTF-8（不带 BOM）**，并确认终端字体支持中文。

选择 `10` 载入演示数据后，再选 `8` 输入学号 `2024002`，可以看到：

```text

--------------------------------------------------------------
课程号     课程名          学分  成绩  绩点
--------------------------------------------------------------
CS101         程序设计基础          4.00  78.00  3.00
CS102         数据结构              4.00  59.00  0.00
MA101         高等数学              5.00  64.00  1.50
EN101         大学英语              3.00  72.00  2.30
PE101         体育                  1.00  88.00  3.70
```

## 数据文件格式

数据以纯文本保存（默认 `data.txt`），可以直接用记事本编辑，也方便放进版本控制：

```text
STUDENT <学号> <专业> <姓名>
COURSE  <课程号> <学分> <课程名>
GRADE   <学号> <课程号> <成绩>
```

以 `#` 开头的行是注释，会被忽略。示例：

```text
STUDENT 2024001 计算机科学与技术 张三
COURSE CS101 4.0 程序设计基础
GRADE 2024001 CS101 92.0
```

> 注意：专业、姓名这类可能含空格的字段写在**行的末尾**，程序会把该行剩余部分整体作为一个字段读取。
> 仓库里的 `sample_data.txt` 是一份可以直接使用的演示数据。

## 学分与绩点计算规则

- **已修学分**：所有已录入成绩课程的学分之和
- **已获学分**：成绩 `>= 60` 的课程学分之和（不及格不计学分）
- **加权平均分**：`Σ(学分 × 成绩) / Σ学分`
- **平均绩点 GPA**：`Σ(学分 × 绩点) / Σ学分`，单科绩点按 4.0 制换算：

| 百分制成绩 | 绩点 | 百分制成绩 | 绩点 |
| --- | --- | --- | --- |
| 90 ~ 100 | 4.0 | 72 ~ 74 | 2.3 |
| 85 ~ 89 | 3.7 | 68 ~ 71 | 2.0 |
| 82 ~ 84 | 3.3 | 64 ~ 67 | 1.5 |
| 78 ~ 81 | 3.0 | 60 ~ 63 | 1.0 |
| 75 ~ 77 | 2.7 | 0 ~ 59 | 0.0 |

## 实现要点

- **`CreditManager` 类**：把学生、课程、成绩三张「表」封装在内部，对外只暴露
  添加 / 删除 / 查询 / 统计接口，界面代码不直接碰容器。
- **级联删除**：删除学生或课程时，会一并清理关联的成绩记录，避免脏数据残留。
- **输入健壮性**：菜单与数值输入都走 `readInt` / `readDouble`，非法输入只提示、不崩溃，
  也不会因 `cin` 失败而陷入死循环；输入流结束（Ctrl+Z 或重定向输入用完）时程序正常退出。
- **统计容错**：`report()` 遇到「课程已被删除的成绩记录」会自动跳过，不会算出错误学分。
- **中文对齐**：中文在终端占 2 个显示宽度而 `std::setw` 按字节数补齐，所以表格的中文列
  改用制表符对齐，数字列保留 `setw`。
